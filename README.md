# Hardik Nagar

Static portfolio site for [hardiknagar.studio](https://hardiknagar.studio/).

## Run locally

Open `index.html` directly in a browser. The site has no build step or dependency install requirement.

## Publish

Upload the project files to any static host. `CNAME` is included for GitHub Pages custom-domain support.

For the domain to resolve, add the host's required DNS records at the domain registrar. GitHub Pages commonly uses:

- `A` records for the apex domain pointing to GitHub Pages
- A `CNAME` record for `www` pointing to the Pages hostname
